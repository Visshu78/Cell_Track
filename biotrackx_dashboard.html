Architecture Modules
🔍
Module 1: Spatial Encoder
ResNet-18-style CNN extracting per-frame feature maps F ∈ R^(H/8 × W/8 × 128). 4-shift TTA augmentation computes aleatoric centroid variance σ² per cell.
encoder.py
⚡
Module 2: ST-GT Transformer
Spatio-temporal cross-frame attention across ALL T frames. Cell object queries maintain identity. DivisionQueryHead spawns daughter queries for dividing cells.
transformer.py
🧬
Module 3: Erlang Bio Prior
Tracks cell age per query. Penalizes biologically implausible divisions via Erlang(α=2, β) cell-cycle lifetime distribution. β is a learnable parameter.
erlang_prior.py
📐
Module 4: Joint Loss
L_total = λ₁·L_track (Hungarian) + λ₂·L_seg (Dice+BCE) + λ₃·L_div (BCE) + λ₄·L_bio (Erlang). Fully differentiable, trains end-to-end.
loss.py
🧠
Master Model
BioTrackX nn.Module composing all three modules. forward_inference() returns tracked_masks, lineage_graph, and uncertainty_maps. ~1.44M parameters.
model.py
🔌
Inference Adapter
Drop-in replacement for Trackastra. run_biotrackx_inference() returns (tracked_masks, DiGraph) — identical interface. Saves TTA uncertainty .npy maps.

# BioTrack-X Joint Loss — Four-Component Differentiable Objective L_total = ( λ₁ · L_track # λ₁=1.0 — Hungarian bipartite centroid regression (Smooth-L1) + λ₂ · L_seg # λ₂=0.5 — Dice + BCE mask reconstruction loss + λ₃ · L_div # λ₃=1.0 — Division binary cross-entropy (DivisionQueryHead) + λ₄ · L_bio # λ₄=0.3 — Erlang biological cell-cycle prior ) # L_track: Optimal assignment via Hungarian algorithm L_track = SmoothL1( pred_centroids[matched], gt_centroids[matched] ) # L_bio: Erlang CDF-based biological plausibility cost L_bio(Age_i) = -log[ ∫₀^Age_i Erlang(t; α=2, β) dt ] # f(t; α=2, β) = β² · t · exp(-βt) (Erlang PDF, shape α=2) # β is a learnable parameter initialized to 0.2 (mean cycle ~10 frames) # L_seg: Soft Dice + Binary Cross-Entropy L_seg = DiceLoss(pred_mask, gt_mask) + BCE(pred_mask, gt_mask)
